# Контракт генерации черновика

Существующий `POST /api/generate`, его запрос и ответ не меняются. Новый экран использует отдельный `POST /api/draft`. Запрос: `{ "answers": { "daily_tasks": "…", "current_project": "…", "next_six_months": "…", "tools_and_knowledge": "…" } }` — четыре подтверждённых непустых ответа до 4000 символов каждый; посторонние поля отклоняются.

Ответ содержит единый документ `blocks`: переменное число абзацев и маркированных списков с необязательными общими заголовками. Каждый содержательный пункт имеет `text`, `source_topic` и дословный непустой фрагмент `evidence` соответствующего ответа. Четыре секции по вопросам не требуются. Лишние поля, пустые блоки и неподтверждённые фрагменты отклоняются. Неподтверждённые числа и имена отклоняются эвристически. Модель инструктирована формулировать и группировать только известные факты, не добавлять требования или условия.

Проверки оснований и эвристики не доказывают смысловую корректность перефразирования: черновик необходимо проверить человеку. Модель `gemini-3.5-flash-lite` вызывается с `store: false`, строгой схемой и безопасными ошибками; внешние источники не используются. При пересоздании после уточнения ответов требуется подтверждение; ошибки и запоздавшие ответы не уничтожают ручные правки.

Контракт редактора и план тестов: `rich-draft-contract.md`. Контракт оценки по четырём темам: `completeness-api.md`.
